## 把回答前的步骤展开

这个面向小学教育的 RAG 练习，从 PDF 的结构化解析开始，经过语义增强、分块和向量索引，再进入查询改写、召回、重排、过滤与生成。公开 README 把各段思路分别列出，便于观察资料怎样一步步成为回答的依据。

解析使用 MinerU 处理布局、表格和公式；分块先依据 Markdown 结构组织章节与知识点，再通过递归切分控制长度。文件哈希检测避免重复处理未修改资料，删除文件的清理逻辑则帮助保持数据源与索引一致。

## 召回之后还需要选择

向量表示采用 bge-m3，查询改写补充上下文与指代信息。召回后的候选片段再由 Cross-Encoder 重排，并经过阈值过滤。生成部分区分新题目的解答与延续对话，历史记录保留有限轮次。

这些配置描述的是项目的实现选择，不能单凭一个阈值就证明回答不会出错。README 也留下了具体问题：复杂问题需要较多资料，简单问题可能受到无关片段干扰；英文词形变化还可能影响召回。

## 把未解决的问题留下来

知识库动态维护、文档质量过滤、标签增强和检索数量调整都仍在待改进清单中。代码由 AI 辅助并使用现成模块。作为学习记录，它的价值也在于把当前思路与下一步问题同时保存，方便继续检验。
