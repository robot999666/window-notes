## 让知识点对应具体代码

这份 C++ 数据结构课程学习仓库，按基础练习、顺序表、单链表、顺序栈、顺序队列和二叉树整理代码。目录从线性结构逐渐走向树，便于按知识点阅读，也方便在复习时找到对应实现。

同样是保存一组数据，不同结构会带来不同访问规则。顺序表练习增删查改，链表涉及指针与动态内存，栈与队列区分后进先出和先进先出，二叉树则连接遍历与递归。抽象定义由这些具体操作落到代码里。

## 阅读时可以关注什么

可以先看结构如何表示数据，再查看初始化、插入、删除与访问的入口。对于指针结构，留意节点之间怎样连接；对于栈与队列，关注边界与状态；对于树，沿着遍历顺序追踪一次递归展开。

这些是阅读学习代码的建议，并非新增的项目验证结果。公开 README 提供编译运行示例与注释说明，适合先选择一类结构理解，再对照相邻结构的差异。
